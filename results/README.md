# FaceNet — Evaluation Results

## Overview

This directory contains the experimental results generated by the FaceNet-based face recognition system using the Yale Face Database.

The system uses a pretrained FaceNet model for facial feature extraction and a Support Vector Machine (SVM) classifier for identity recognition.

## Experimental Configuration

| Parameter | Value |
|---|---|
| Dataset | Yale Face Database |
| Selected Individuals | 10 |
| Selected Images | 110 |
| Feature Extractor | FaceNet |
| Embedding Dimension | 128 |
| Classifier | Support Vector Machine (SVM) |
| SVM Kernel | Linear |
| C Parameter | 1.0 |
| Validation | 3-Fold Cross-Validation |

## Performance Summary

| Metric | Average Score |
|---|---:|
| Accuracy | 99.10% |
| Precision | 99.33% |
| Recall | 99.17% |
| F1-score | 99.15% |

*These values are the preliminary results recorded in the initial experiment. Refer to metrics.csv for the fold-level measurements.*

## Files Description

| File | Description |
|---|---|
| `metrics.csv` | Performance metrics for each validation fold |
| `predictions.csv` | Actual and predicted identity labels |
| `classification_report.csv` | Precision, recall and F1-score by identity |
| `variation_accuracy.csv` | Recognition accuracy across facial variations |
| `confusion_matrix.png` | Visualization of classification performance |
| `variation_accuracy.png` | Accuracy across different facial variations |

## Evaluation Methodology

1. Load facial images from the Yale Face Database.
2. Select 10 individuals automatically.
3. Preprocess images into the required FaceNet input format.
4. Extract 128-dimensional facial embeddings.
5. Normalize the extracted embeddings.
6. Train a linear SVM classifier.
7. Evaluate using three-fold cross-validation.
8. Calculate accuracy, precision, recall and F1-score.
9. Analyze performance across facial variations.

## Result Interpretation

The preliminary experiment achieved high identity recognition accuracy on the selected Yale dataset.

Further analysis includes:
- Classification errors between individuals.
- Recognition performance under different facial variations.
- Consistency across validation folds.
- Computational efficiency.

## Limitations

- The experiment uses only 10 individuals.
- The dataset is relatively small.
- Results are specific to the selected dataset and experimental setup.
- High accuracy on this dataset does not guarantee equivalent performance in real-world environments.
