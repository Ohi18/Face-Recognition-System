# Face Recognition Notebooks

## FaceNet Implementation

- Notebook: Facenet.ipynb
- Dataset: Yale Face Database
- Selected identities: 10
- Feature extractor: Pretrained FaceNet
- Classifier: Support Vector Machine (SVM)
- Validation: 3-Fold Cross-Validation

## Evaluation

The notebook includes:
- FaceNet embedding extraction
- SVM classification
- Accuracy, precision, recall and F1-score
- Confusion matrix
- Facial-condition-wise evaluation
