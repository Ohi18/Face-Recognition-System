# Dataset Documentation

## Dataset Name
Yale Face Database

## Dataset Information
- Total Images: 165
- Total Individuals: 15
- Images per Individual: 11
- Image Format: GIF
- Image Type: Grayscale

## Facial Variations
- Happy
- Sad
- Normal
- Surprised
- Sleepy
- Wink
- Glasses
- No Glasses
- Center Light
- Left Light
- Right Light

## Dataset Used in This Project
- Selected Individuals: 10
- Selected Images: 110

## Dataset Source
University of California San Diego:
https://vision.ucsd.edu/datasets/yale-face-database

Original dataset files are stored in Google Drive.
Raw dataset images are not included in this repository.
