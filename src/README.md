
# Source Code

This directory contains reusable Python source
code for the Face Recognition System.

## FaceNet Implementation

The FaceNet pipeline includes:

1. Image loading
2. Image preprocessing
3. FaceNet embedding extraction
4. Feature normalization
5. SVM classification
6. Model evaluation

## Implementation Environment

- Python
- TensorFlow
- DeepFace
- Scikit-learn
- NumPy
- Pandas
- Matplotlib

## Main Implementation

The initial implementation is available in:

notebooks/Facenet.ipynb

Reusable Python modules will be added here
as the implementation is organized.
