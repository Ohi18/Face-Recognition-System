# Face Recognition Models

This directory contains documentation about the
models used in the comparative face recognition project.

## Model 1: FaceNet

- Architecture: Inception ResNet V1
- Implementation: DeepFace
- Model Type: Pretrained
- Embedding Dimension: 128
- Input Size: 160 x 160 x 3
- Purpose: Facial feature extraction

## Classifier

- Algorithm: Support Vector Machine (SVM)
- Kernel: Linear
- C Parameter: 1.0

## Other Group Models

1. FaceNet
2. ArcFace
3. SFace

## Note
Pretrained model weights are downloaded through
the respective model libraries when required.

Model weights are not stored in this repository.
